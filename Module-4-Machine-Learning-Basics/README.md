# Module 4 - Machine Learning Basics 🤖

This module covers the fundamentals of Machine Learning using Python
and Scikit-learn.

## Topics Covered

- Introduction to Machine Learning
- Supervised and Unsupervised Learning
- Features (X) and Target (y)
- Training and Testing Data
- Train-Test Split
- Model Training and Prediction
- Regression and Classification
- Model Evaluation

## Project 1: Student Score Prediction 🎓

Built a Linear Regression model to predict student scores based on
hours studied.

### Concepts Used
- Linear Regression
- Train-Test Split
- model.fit()
- model.predict()
- MAE
- MSE
- RMSE
- R² Score
- Regression Visualization

## Project 2: Iris Flower Classification 🌸

Built a Decision Tree Classifier to predict Iris flower species using
flower measurements.

### Concepts Used
- Classification
- Decision Tree Classifier
- Train-Test Split
- Accuracy Score
- Confusion Matrix
- Prediction on new data
