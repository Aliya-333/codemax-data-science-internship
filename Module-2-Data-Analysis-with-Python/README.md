# Module 2 - Data Analysis with Python 📊

## Codemax Data Science Internship

This folder contains my work for **Module 2: Data Analysis with Python**
as part of my Data Science Internship at **Codemax Digital Solutions**.

## 📌 Project: Sales Data Analysis

In this project, I worked with a sales dataset using Python to understand
the basic workflow of real-world data analysis.

The project includes data exploration, data cleaning, handling missing
values, product-level analysis, sales analysis, and data visualization.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Excel / CSV

## 📚 Tasks Completed

- Imported an Excel sales dataset using Pandas
- Explored the dataset using `head()`, `info()`, `shape`, and `describe()`
- Checked column names and data types
- Identified missing values
- Investigated missing data before cleaning
- Created a cleaned product-level dataset
- Analyzed total quantity and sales value
- Calculated basic sales statistics
- Identified top-selling products
- Grouped products using Pandas `groupby()`
- Analyzed invoice-level sales information
- Performed basic date-based analysis
- Created sales visualizations using Matplotlib
- Exported cleaned data and product summaries to CSV

## 📈 Analysis Performed

The project focuses on:

- Total quantity sold
- Total sales value
- Average product rate
- Product-wise sales performance
- Top products by sales value
- Top products by quantity sold
- Gross sales analysis
- Tax analysis
- Daily sales analysis

## 📊 Visualizations

Visualizations were created to understand:

- Top 10 products by sales value
- Top 10 products by quantity sold
- Daily sales trends
