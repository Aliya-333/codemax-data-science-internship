# Module 3 - Data Visualization 📊

## Codemax Data Science Internship

This folder contains my work for **Module 3: Data Visualization**
as part of my Data Science Internship at **Codemax Digital Solutions**.

## 📌 Overview

In this module, I focused on visualizing sales data using Python.
I used **Matplotlib** and **Seaborn** to create different types of
charts and understand patterns, trends, distributions, and
relationships in the dataset.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## 📊 Visualizations Created

### 1. Bar Chart
Created a bar chart to compare the top products based on sales value.

### 2. Line Chart
Created a line chart to visualize sales trends over time.

### 3. Pie Chart
Created a pie chart to show the quantity share of the top-selling
products.

### 4. Histogram
Created a histogram to understand the distribution of product rates.

### 5. Scatter Plot
Created a scatter plot to study the relationship between quantity
sold and sales value.
