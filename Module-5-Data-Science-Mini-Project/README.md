# Module 5 - Data Science Mini Project 📊

## Student Performance Analysis

This project was completed as part of Module 5 of my Data Science
Internship at Codemax Digital Solutions.

The objective of this project is to analyze student performance data,
explore different factors related to academic performance, create
visualizations, and generate meaningful insights from the dataset.

## 🎯 Project Objectives

- Explore and understand the student performance dataset
- Clean and prepare the data for analysis
- Check and handle missing values and duplicate records
- Perform Exploratory Data Analysis (EDA)
- Analyze factors related to student performance
- Create meaningful data visualizations
- Identify patterns and insights from the data

## 🔍 Analysis Performed

The project explores factors such as:

- Study hours
- Attendance
- Previous GPA
- Assignment, midterm, and final scores
- Department
- Gender
- Sleep hours
- Stress level
- Part-time job
- Internet access
- Extracurricular activities

Correlation analysis was also performed to understand relationships
between numerical variables.

## 📊 Data Visualizations

Different visualizations were created using Matplotlib and Seaborn,
including:

- Bar Charts
- Scatter Plots
- Box Plots
- Correlation Heatmap
- Dashboard-style visualizations

## 🛠️ Tools & Technologies

- Python

- Seaborn

- GitHub
