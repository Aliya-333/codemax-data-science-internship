# 📊 Module 2 - Data Analysis with Python

 📌 Overview

This module focuses on learning the fundamentals of data analysis using Python.

During Days 5–8 of my Data Science Internship at Codemax Digital Solutions, I worked with datasets using Pandas and NumPy. The module covers importing, exploring, cleaning, organizing, and analyzing data to extract useful insights.

---

 🎯 Objectives

- Understand the basic data analysis workflow
- Work with Pandas and NumPy
- Import CSV datasets into Google Colab
- Explore and understand datasets
- Identify and handle missing values
- Detect and remove duplicate records
- Clean and organize data
- Perform basic statistical analysis
- Filter and group data
- Extract meaningful insights from datasets
